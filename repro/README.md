# Reproducibility Experiment — repro/

This directory contains the scripts added for the FTEC5660 reproducibility coursework.

## Scripts

**`run_experiments.py`** — runs all five experimental conditions in order:
1. Harness-MU full, none-attack dataset
2. Muses-Bench baseline (no harness), none-attack
3. Harness-MU full, fake_authorized attack dataset
4. Muses-Bench baseline, fake_authorized attack
5. Harness-MU ablation (ComplianceChecker disabled), fake_authorized attack

```bash
python repro/run_experiments.py --model deepseek-chat --trials 3
```

`--trials 3` runs each condition 3 times to capture variance from the
stochastic worker (temperature 0.7). Use `--trials 1` for a quick check.

**`make_ablation_config.py`** — generates `harness_mu/config/ablation_no_cc.yaml`
from `my_experiment.yaml` with `compliance_checker: false`. Called automatically
by `run_experiments.py`; can also be run standalone:

```bash
python repro/make_ablation_config.py
```

**`aggregate_results.py`** — reads all `eva.json` and `baseline_*.jsonl` files
under `results/` and prints a comparison table, then saves it as
`results/comparison_table.json`.

```bash
python repro/aggregate_results.py
```

## Modification

The ablation disables the `ComplianceChecker` module, which is the
deterministic fail-closed layer that overwrites any Worker response leaking
sensitive tokens to unauthorized users. The module makes no LLM calls, so
disabling it is a clean single-variable change. The expected outcome is that
privacy score drops on attack datasets (where the Worker alone is not
sufficient), while results on the none-attack dataset are unchanged.

The contribution of the ComplianceChecker is directly readable from
`eva.json` as `avg_boundary_delta_privacy` (full harness run) without
needing the ablation run — the ablation provides the complementary
measurement.
